## 3. Services and starting prices

Prices are "from" figures in naira: the smallest realistic version of the service. The exact price is a written quote after a free discovery call. The website also shows approximate dollar and cedi equivalents (for example, ₦450,000 is shown as about $300).

1. Website Development, from ₦450,000. Modern, mobile-first, SEO-structured websites, built on Next.js (WordPress when a client's team needs to edit pages daily). Includes custom design matched to the brand, on-page SEO (metadata, headings, sitemap, schema), fast page loads, contact and lead forms wired to email or a CRM, basic analytics, and a short handover guide. Process: scope and sitemap, design sign-off on key pages, build, launch and handover. Hosting and domain: AnalytIQ can set these up or work with the client's existing provider.
2. AI Automation, from ₦300,000. A process audit, then automated workflows that connect existing tools (forms, sheets, email, WhatsApp, CRM) with AI steps where it adds judgement (drafting, classifying, summarising, routing). 3. Power BI Dashboards, from ₦350,000. Data audit, cleaned and modelled data, interactive dashboards for sales, operations or finance, scheduled refresh, and a training session. The client does not need to already use Power BI (many start with Excel or POS and accounting exports). A focused single-department dashboard usually takes two to three weeks from discovery to handover; company-wide, multi-source reporting takes longer.
4. Custom Software, from ₦900,000. A scoped requirements document before any code, a working web application matched to the workflow, user roles and permissions, a database that can grow, deployment and a handover walkthrough. Built with React or Next.js, Node.js and PostgreSQL or MySQL. If existing software already covers the need, AnalytIQ says so. After-launch support is on a retainer or ad-hoc basis agreed before the project starts.
5. AI WhatsApp Assistant, from ₦400,000. WhatsApp Business API setup, an AI assistant scripted around the client's real products, services and tone, clear handoff to a human, basic conversation analytics, documentation and team training. It can take straightforward orders; complex inventory-checked or multi-item ordering is scoped with Custom Software or the inventory solution. The official WhatsApp Business API is recommended for reliability.
6. Digital Consulting, from ₦200,000. A structured review of operations, tools and pain points, a written assessment of the highest-impact opportunities, and a prioritised roadmap with realistic cost and timeline. It is independent, so an honest recommendation can be "no new technology". AnalytIQ can implement the recommendations or support an in-house team.

Not sure which service? Start with a conversation about the problem, or Digital Consulting.

## 7. Frequently asked questions

- Do you only work with large companies? No. SMEs, retail and distribution businesses, schools, hospitals, restaurants and institutions. Scope is sized to the business.
- Do I need to be in Abuja? No. Clients anywhere in Nigeria or abroad.
- How do we get started? Message on WhatsApp, start a project on the website, or book the free 15-minute call. AnalytIQ says honestly whether it is a good fit before any commitment.
- Do we need to replace our current tools? Usually not. Automation connects existing tools.
- Is AI reliable enough to run unsupervised? Customer-facing or decision-critical steps get human review. Internal sorting, drafting and summarising can run on their own.
- What if an automation breaks? Workflows send error notifications so a failure is caught immediately.
- Next.js or WordPress? WordPress if the team edits content daily without a developer; Next.js for speed, custom features or a lean marketing site.
- Will the website work on slow mobile data? Yes, performance is treated as a requirement.
- Can I edit the website myself later? Yes. WordPress natively; Next.js through a simple content structure or a headless CMS, plus a handover walkthrough.
- Will the WhatsApp assistant sound robotic? It is scripted around the client's own products and tone and hands over to a human quickly.
- Is consulting just a sales pitch? No. The recommendation may be a smaller project, a different vendor or no new technology.
- Why "from" prices? Cost depends on scope. The exact written price comes after the discovery call.
